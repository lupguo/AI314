# 探索期 / PoC 研发模式补丁

> **生效范围**：仅在项目早期验证核心可行性（0 -> 0.1）期间生效。一旦验证通过决定转入正式产品开发，必须卸载此模式并按 L0/L1 标准重构。

## 1. 临时豁免条款（覆盖 L0 宪法对应限制）

- **豁免复杂目录拓扑**：允许在 `playground/` 或单文件脚本中快速串联端到端链路，暂不强制拆分为完整的 DDD/分层目录。
- **豁免单文件 300 行上限**：原型脚本允许单文件放宽至 600 行以内，优先保证上下文连贯与快速修改。
- **放宽 TDD 前置要求**：允许先写出能跑通的 Happy Path 原型，暂不要求补全边界异常测试，但**必须保留 `--dry-run` 或 Mock 样本以验证核心输入输出**。

## 2. 依然不可逾越的底线

- **安全红线不豁免**：密钥、Token、API Key 依然必须走 `.env` 注入，严禁硬编码进原型代码。
- **转正清理铁律**：验证结束后，必须在 `docs/00-plans/` 中输出《验证结论与正式重构计划》，严禁直接把 PoC 面条代码当作正式架构继续堆砌功能。
